# SHREE JI CONNECT V3

Customer CRM + Order Management + WhatsApp Center for SHREE JI GOLD CREATOR LLP.

## Included
- Customer CRM
- Manual customer WhatsApp number
- Customer history
- Manual Exhibition Name / Expo entry
- Order Number
- Item
- Total Order Weight
- Started Weight
- Automatic Balance Weight
- Start Date
- Expected Finish
- Actual Finish
- Delivery Date
- Status
- Order Value
- Advance with GPay / Cash
- Gold Touch
- Screw Type
- Lady's Ring Size: manual number (9–15)
- Gents Ring Size: manual number (17–25)
- Order Notes
- WhatsApp Center
- Message Templates
- Backup & Restore
- Owner Dashboard
- App icon

## Example
If Total Order Weight = 500g and Started Weight = 300g:
Balance Weight = 200g.

## GitHub Pages
1. Extract this ZIP.
2. Upload all files to your GitHub repository.
3. Make sure `index.html`, `icon.svg`, `manifest.json` and `sw.js` are in the same folder.
4. Enable GitHub Pages.
5. Open the generated Pages URL.

## Important
This app stores data in the browser's localStorage. Use Backup & Restore regularly so customer/order data is not lost when browser storage is cleared.
