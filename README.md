# SHREE JI CONNECT V3

Customer CRM + Order Management + Direct/SM Database Reports + WhatsApp.

## Included
- Customer CRM
- Exhibition manual entry
- Order type: Direct / SM
- Total / Started / Balance weight tracking
- Advance as GPay/Cash text entry
- Ring size manual number entry
- Owner Database Reports
- Exhibition summary
- Follow-ups
- WhatsApp center and message templates
- Backup & Restore
- Settings
- PWA manifest + service worker

## GitHub Pages
Upload `index.html`, `manifest.json`, `sw.js`, and `README.md` to the repository root and enable GitHub Pages.

## Important
Data is stored in the browser's localStorage. Use Backup & Restore regularly.
