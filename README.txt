SHREE JI CONNECT - FULL VERSION

Included:
- Dashboard and statistics
- Customer add/edit/delete
- Customer fields: Customer Name, Mobile No, Shop Name, Place
- Order add/edit/delete
- Order fields: Order No, Weight, Gold Touch, Advance, Status, Order Date
- Previous order history inside each customer
- Order search
- WhatsApp direct message
- Customer-linked WhatsApp: selecting a customer automatically fills the saved mobile number
- Quick WhatsApp button on every customer card
- WhatsApp image share fallback
- Bulk WhatsApp chat opening with message templates
- Template create/edit/delete
- Placeholders: {{name}}, {{phone}}, {{company}}, {{orderNo}}, {{weight}}, {{touch}}, {{advance}}, {{status}}, {{date}}
- JSON backup export/import
- Reset data
- PWA manifest + service worker

IMPORTANT:
WhatsApp can prefill the saved customer number, but messages are not sent automatically; the WhatsApp chat must still be opened/sent by the user.
Data is stored in browser localStorage. Export backups regularly.
WhatsApp actions open chats with prepared text; the app does not send messages automatically.
